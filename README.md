# T-Invest Bot Mobile v0.1

Android-приложение для безопасного чтения портфеля T-Инвестиций.

## Что уже есть

- подключение к официальному T-Invest REST API;
- получение списка открытых брокерских счетов;
- переключение между счетами;
- загрузка портфеля;
- общая стоимость, акции, облигации, деньги/валюты;
- доходность портфеля и дневной результат;
- список позиций: тикер, тип, количество, текущая и средняя цена;
- локальный индикатор концентрации позиции;
- токен шифруется Android Keystore и не записывается в исходный код;
- кнопка полного удаления токена с телефона.

## Критически важно

Версия 0.1 работает **только на чтение на уровне кода**: в проекте отсутствуют вызовы OrdersService/StopOrdersService и нет методов отправки торговых заявок.

Используйте только **read-only token** T-Invest API. Не отправляйте токен в чат, почту или мессенджеры.

## Как получить токен

В личном кабинете Т-Инвестиций откройте настройки API-токенов и выпустите токен «только для чтения». Официальная документация отмечает, что с телефона управление токенами может перенаправлять в мобильное приложение, поэтому при необходимости откройте сайт в браузере в режиме «Версия для ПК».

Документация: https://developer.tbank.ru/invest/intro/intro/token

## Сборка

Требования:
- JDK 17
- Android SDK 35
- Gradle 8.9+

Команда:

```bash
gradle :app:assembleDebug
```

APK после сборки:
`app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions

При каждом push в main, pull request и ручном запуске workflow собирается debug APK.
Откройте Actions → Build Android APK → успешный запуск → Artifacts →
TInvestBotMobile-debug.apk. Скачайте ZIP и извлеките одноимённый APK для установки.
Срок хранения артефакта — 30 дней. Для сборки токен T-Invest не нужен.

Сборка: JDK 17, Gradle 8.10.2, Android Gradle Plugin 8.7.3, SDK 35.
Минимальная версия Android — 8.0 (API 26).
Клиент разрешает только GetAccounts и GetPortfolio; перенаправления отключены.
Права самого токена задаются при его выпуске в T-Invest: выбирайте только чтение.
